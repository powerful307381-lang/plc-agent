# 西门子博途 V16 (TIA Portal V16) SimaticML 样板结构分析说明

> **基准依据**：本说明文档由本机实际运行的博途 V16 (v1600.0.3102.1) + S7-1200 (CPU 1214C V4.4) 真实导出的样板 XML 全量逆向解析生成。
> 后续所有的梯形图 (LAD) XML、定时器 DB XML、变量表 XML 生成器**必须以此样板数据结构为 100% 绝对基准**。

---

## 一、 文件头与核心命名空间 (Namespaces)

| 节点 / 属性 | 博途 V16 实际导出规范 | 说明 |
| :--- | :--- | :--- |
| **XML 声明** | `<?xml version="1.0" encoding="utf-8"?>` | 强制 UTF-8 编码，单个 UTF-8 BOM |
| **Engineering 版本** | `<Engineering version="V16" />` | 必须为 V16，严禁误写为其他版本 |
| **接口命名空间 (Interface)** | `http://www.siemens.com/automation/Openness/SW/Interface/v4` | 用于 FC、DB、OB1 的 `<Sections>` 根节点 |
| **网络图形命名空间 (FlgNet)** | `http://www.siemens.com/automation/Openness/SW/NetworkSource/FlgNet/v4` | 用于每一个梯形图程序段的 `<FlgNet>` 根节点 |
| **对象 ID 属性** | `ID="0"`, `ID="3"`, `ID="8"`... | 文档级对象唯一标识符（十六进制字符串） |
| **网络 UId 属性** | `UId="21"`, `UId="22"`... | 单个 FlgNet 内唯一，推荐从 21 起递增分配 |

## 二、 核心指令与元件语法 (Parts & Wires)

### 1. 常开触点与常闭触点 (Contact)
* **常开触点**：
  ```xml
  <Part Name="Contact" UId="24" />
  ```
* **常闭触点**（取反常闭）：
  ```xml
  <Part Name="Contact" UId="25">
    <Negated Name="operand" />
  </Part>
  ```
* **操作数引用 (Access)**：
  ```xml
  <Access Scope="GlobalVariable" UId="21">
    <Symbol><Component Name="SB1_测试启动" /></Symbol>
  </Access>
  ```

### 2. 输出线圈、置位与复位 (Coil / SCoil / RCoil)
* **普通线圈**：`<Part Name="Coil" UId="26" />`
* **置位线圈 (S)**：`<Part Name="SCoil" UId="26" />`
* **复位线圈 (R)**：`<Part Name="RCoil" UId="28" />`

### 3. 并联分支 (Or)
* **`O` 节点定义**：
  ```xml
  <Part Name="O" UId="27">
    <TemplateValue Name="Card" Type="Cardinality">2</TemplateValue>
  </Part>
  ```
* **接线规程**：Powerrail 分别连入并联触点的 `in`，支路输出连入 `O` 的 `in1` 与 `in2`，`O` 的 `out` 汇流输出给后续串联触点。

### 4. TON 延时定时器方框指令（⭐重大关键发现）
* **时间常量的 Access Scope**：
  * **必须为 `TypedConstant`**（之前使用 `LiteralConstant` 会报错！）：
    ```xml
    <Access Scope="TypedConstant" UId="22">
      <Constant>
        <ConstantValue>T#5S</ConstantValue>
      </Constant>
    </Access>
    ```
* **TON 元件定义**：
  ```xml
  <Part Name="TON" Version="1.0" UId="25">
    <Instance Scope="GlobalVariable" UId="26">
      <Component Name="全局定时器" />
      <Component Name="T1_样板" />
    </Instance>
    <TemplateValue Name="time_type" Type="Type">Time</TemplateValue>
  </Part>
  ```
* **引脚连线**：
  * `IN`: 逻辑使能端输入；
  * `PT`: 设定时间端（连入 `TypedConstant` 的 UId）；
  * `Q`: 延时到达输出端（连至后续线圈或下一触点）；
  * `ET`: 经过时间端（可选，连入 Time 变量）。

### 5. 上升沿检测指令 (P_TRIG)（⭐重大关键发现）
* 在博途 V16 LAD SimaticML 中，上升沿元件的内部 Part 名称为 **`PBox`**：
  ```xml
  <Part Name="PBox" UId="25" />
  ```
* 上方边沿存储位：通过一个 `GlobalVariable` 的 `Access` 连入其 `bit` 引脚。

### 6. 比较运算与数据传送 (Compare & Move)
* **比较 `>=`**：
  ```xml
  <Part Name="Ge" UId="25">
    <TemplateValue Name="SrcType" Type="Type">Int</TemplateValue>
  </Part>
  ```
* **传送 `MOVE`**：
  ```xml
  <Part Name="Move" UId="26" DisabledENO="true">
    <TemplateValue Name="Card" Type="Cardinality">1</TemplateValue>
  </Part>
  ```

### 7. OB1 中的 FC 块调用 (Call)（⭐重大关键发现）
* **Call 元件定义**（必须直接使用 `<Call>` 标签，严禁写为 `<Part Name="Call">`）：
  ```xml
  <Call UId="21">
    <CallInfo Name="FC-样板" BlockType="FC" />
  </Call>
  ```
* **接线**：Powerrail 直接连入 `<NameCon UId="21" Name="en" />`。

```xml
<?xml version="1.0" encoding="utf-8"?>
<Document>
  <Engineering version="V16" />

    <AttributeList>
      <Interface>
        <Sections xmlns="http://www.siemens.com/automation/Openness/SW/Interface/v4">
          <Section Name="Static">
            <Member Name="T1_样板" Datatype="IEC_TIMER" Remanence="NonRetain" Accessibility="Public" />
          </Section>
        </Sections>
      </Interface>
      <MemoryLayout>Optimized</MemoryLayout>
      <Name>全局定时器</Name>
      <Number>1</Number>
      <ProgrammingLanguage>DB</ProgrammingLanguage>
    </AttributeList>
  </SW.Blocks.GlobalDB>
</Document>
```

## 五、 本机样板与 [05_SimaticML_LAD防报错规范.md](../references/05_SimaticML_LAD防报错规范.md) 的差异比对总结

| 5 | **置位复位** | SCoil / RCoil | 完全一致：`<Part Name="SCoil" />` / `<Part Name="RCoil" />` | **完全按样板克隆** |

## 六、 功能块 FB 与多重背景样板（[FB_样板.xml](FB_样板.xml)）

1. **根节点与接口定义**：使用 `<SW.Blocks.FB>`，在 `<Interface><Sections>` 中声明 `Input`、`Output`、`InOut`、`Static`（可放多重背景定时器如 `Datatype="TON_TIME"`）、`Temp`、`Constant`。
2. **块内局部变量引用**：在 `<FlgNet>` 中使用 `<Access Scope="LocalVariable" UId="...">` 引用接口参数或 `Static` 成员（如 `<Component Name="stat_KT" /><Component Name="Q" />`）。
3. **块调用与背景 DB**：在 `OB1` 或上层 `FC`/`FB` 中调用时，使用 `<Call UId="..."><CallInfo BlockType="FB" Name="..."><Instance Scope="GlobalVariable" ...>`（单背景 DB）或 `<Instance Scope="LocalVariable" ...>`（多重背景），并为实参建立 `<Parameter Name="..." Section="Input|Output|InOut" Type="..." />` 与对应 `<Wire>`。
4. **未包含在本目录的指令/类型（严格按 R10 执行）**：如目标项目需使用新指令或未覆盖的工艺对象，请先通过 `scripts/tia_bridge_core.ps1 -Action export-all` 从本机 TIA Portal V16 导出 1 份最小实测 XML 作为克隆母本，严禁凭记忆手写未知 Schema。

### V16 原生 SimaticML `<Part Name>` 与属性实测速查（严禁凭记忆猜名）
- **下降沿检测**：`<Part Name="NCoil" />`（或 `NBox`）
- **定时器扩展**：`TOF` / `TP` / `TONR`（`Version="1.0"`，`<TemplateValue Name="time_type" Type="Type">Time</TemplateValue>`）
- **计数器家族**：`CTU` / `CTD` / `CTUD`（`Version="1.0"`，`<TemplateValue Name="value_type" Type="Type">Int</TemplateValue>`）
- **模拟量缩放与转换**：
  - `NORM_X` → `<Part Name="Normalize">`（`SrcType`, `DestType`）
  - `SCALE_X` → `<Part Name="Scale_X">`（`SrcType`, `DestType`）
  - `CONV` → `<Part Name="Convert">`、`ROUND` → `<Part Name="Round">`、`TRUNC` → `<Part Name="Trunc">`
- **数学与比较**：`Add` / `Sub` / `Mul` / `Div` / `Calc`（即 `CALCULATE`）、`Gt` / `Lt` / `Ge` / `Le` / `Ne` / `InRange`
- **字逻辑/移位/块移动**：`And` / `Or` / `Xor` / `Shl` / `Shr`、`MoveBlockI`（即 `MOVE_BLK`）、`FillBlockI`（即 `FILL_BLK`）
- **日期时间**：`RD_LOC_T`（`Version="1.0"`，`date_type:DTL`）、`T_ADD` / `T_SUB`（`Version="1.2"`，`date_type:Time`, `time_type:Time`）
- **工艺与通信**：`PID_Compact` (`Version="2.3"`)、`TSEND_C` (`Version="3.2"`)、`MC_Power` / `MC_Home` / `MC_MoveAbsolute` (`Version="7.0"`)
