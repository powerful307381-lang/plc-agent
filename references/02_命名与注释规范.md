# 02 命名与注释规范

## 1. 变量命名
### 1.1 I/Q 变量（实物信号）
格式：`元器件代号_中文功能`
- 代号**去掉**前导 `-` 和结构前缀 `=` `+`：`-SB0` → `SB0`
- 示例：`SB0_急停按钮`、`SB1_1号电机启动`、`SB2_1号电机停止`、`FR1_1号电机热继`、`KM1_1号电机正转`、`KM2_1号电机反转`、`SQ1_正转限位`、`YV1_推料气缸伸出`、`B1_推料气缸伸出到位`、`HL1_运行指示灯`、`SA1_手自动选择`
- 同一元器件有多个信号时，用功能区分：`U1_变频器故障`、`U1_变频器正转`、`U1_变频器多段速1`

### 1.2 M 变量（全局辅助继电器）
格式：`M_中文功能`（字/双字模拟量换算可用 `MW序号_中文功能`、`MD序号_中文功能`），按设备分组前缀：
- 安全/模式：`M_急停正常`、`M_安全条件满足`、`M_自动模式`、`M_手动模式`、`M_故障复位`
- 设备：`M_1号电机正转请求`、`M_1号电机故障`、`M_星三角_星形完成`
- 报警：`M_报警_1号电机热继`、`M_报警汇总`
- 边沿检测存储位：`M_边沿_启动按钮`（P_TRIG/N_TRIG 专用，不得复用）
- 模拟量/字双字数据：`MW200_变频频率给定`、`MD200_变频频率反馈_Hz`

### 1.3 定时器（`全局定时器` DB 内的成员）
格式：`T序号_中文用途`，例如 `T1_星三角切换`、`T2_星三角换接延时`、`T3_推料伸出超时`

### 1.4 命名校验（必须用脚本校验）
- I/Q 正则：`^[A-Z]{1,3}\d{1,3}[A-Z]?_[\u4e00-\u9fa5A-Za-z0-9_]+$`（允许功能说明中使用 `_` 分隔）
- M 正则：`^(?:M(?:B|W|D)?\d*|ALM|ERR|ST|STEP|CNT|HMI)_[\u4e00-\u9fa5A-Za-z0-9_]+$`（兼容 `M_` 与 `MW30_` / `MD200_` 等字/双字命名）
- **禁用字符**：空格、`.` `/` `\` `"` `'` `%` `:` `;` `,` `(` `)` `[` `]` `{` `}` `&` `#` `-`（`-` 只出现在注释里）
- 长度 ≤ 40 个字符（博途上限是 128，限制得短一些便于梯形图显示）
- 全表不得重名，名称也不得与块名、DB 名重复
- 不得使用 `I0_0` 这类无意义的名字

## 2. 变量注释（EPLAN 标准格式）
```
[页码.列号 | 元器件代号 | 端子号/线号] 中文功能说明(NO/NC)
```
| 示例 | |
|---|---|
| `SB0_急停按钮` | `[3.2 \| -SB0 \| 11-12/101] 急停按钮，按下断开，信号0=急停(NC)` |
| `FR1_1号电机热继` | `[3.4 \| -FR1 \| 95-96/103] 1号电机热继电器，过载断开(NC)` |
| `SB1_1号电机启动` | `[3.5 \| -SB1 \| 13-14/104] 1号电机启动按钮(NO)` |
| `KM1_1号电机正转` | `[6.2 \| -KM1 \| A1/201] 1号电机正转接触器线圈(线圈)` |

规则：
- 注释里的元器件代号**保留** `-` 前缀，与图纸一致。
- 输出（Q）的最后括号写 `(线圈)` / `(指示灯)` / `(电磁阀)` / `(变频器DI)`。
- 安全信号（NC）的说明中必须写明“信号0表示什么”。
- 未确认的字段写 `?`，例如 `[5.3 | -SQ1 | ?/108] 正转限位(NC?) ⚠待确认`，**交付前必须清零**。
- M 变量注释格式：`[FC名/程序段号] 功能说明`；定时器注释写明设定值，例如 `[FC3/NW4] 星形运行时间，设定 T#6S`。

| 块 | 名称 | 编号 |
|---|---|---|
| OB1 | `Main`（保持博途默认名） | 1 |

## 4. 程序段（Network）标题
格式：`NW序号 设备/功能 —— 动作描述`，例如 `NW3 1号电机 —— 正转启动与自锁`。
