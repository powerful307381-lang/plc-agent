# 04 地址分区规划

## 1. I / Q 区与硬件组态对账
- 地址**以博途中的实际硬件组态为准**（阶段 0 读取），图纸地址只作参考；两者冲突时提问用户。
- S7-1200 本体常见：DI 从 `%I0.0` 开始，DQ 从 `%Q0.0` 开始；信号板 SB 与扩展模块（SM）地址以博途组态为准。
- **强制对账门禁**：生成变量表前，必须运行硬件比对，确保图纸中所有非备用 I/O 通道均 100% 落在博途硬件已分配的 `[StartAddress, EndAddress]` 区间内；若存在越界点，必须先向用户汇报并调整博途组态或变量地址。
- 模拟量（仅在启用时）：`%IW64`、`%QW64` 等，以组态为准。

## 2. %M 区分区（从 MB10 开始，MB0～MB9 保留）
| 字节范围 | 用途 | 示例 |
|---|---|---|
| MB0～MB9 | **保留**：系统存储器、时钟存储器（S7-1200 默认 MB1 系统 / MB0 时钟） | 不得使用 |
| MB10～MB19 | 安全与模式 | `M10.0 M_急停正常`、`M10.1 M_安全条件满足`、`M10.2 M_自动模式`、`M10.3 M_手动模式`、`M10.4 M_故障复位` |
| MB20～MB29 | 边沿检测存储位（P_TRIG/N_TRIG 专用） | `M20.0 M_边沿_复位按钮` |
| MB30～MB99 | 设备逻辑，**每台设备独占 10 个字节** | 1号设备 MB30～39，2号设备 MB40～49 … |
| MB100～MB119 | 报警位 | `M100.0 M_报警_1号电机热继` … `M119.7 M_报警汇总` |
| MB120～MB139 | 指示灯 / HMI 预留 | `M120.0 M_运行指示` |
| MW200 起 | 模拟量换算结果（启用时） | `MD200 M_变频频率给定_Hz`（Real，占 4 个字节，按双字对齐） |

规则：
- 如果阶段 0 发现系统/时钟存储器被设在 MB10 及以上的地址，**必须整体平移分区以避开**，并告知用户。
- 位地址按 `.0`～`.7` 顺序紧凑分配；字（Word）/双字（DWord）地址取偶数并避免与位区重叠。
- 生成后输出“地址占用图”，检查是否有重叠。
- **M 变量读写闭环原则**：所有分配的 `%M` 变量除明确标注的白名单（报警汇总、HMI预留、备用）外，必须在梯形图中形成“至少一次写入（线圈/置位/边沿）”与“至少一次读取（触点/条件）”的闭环，严禁出现只写未读或只读未写的孤立中间变量。

## 3. 定时器
- 全部放在全局 DB `全局定时器`（DB1，优化访问），成员类型为 `IEC_TIMER`（TON/TOF/TP 共用）。
- 梯形图中引用方式：`"全局定时器".T1_星三角切换`。
- 不使用 S5 定时器，也不使用 `%T`。

## 4. 计数器（如需要）
放在全局 DB `全局计数器`（DB2），成员类型为 `IEC_COUNTER`（或放在 `FB` 的 `Static` 区作多重背景），命名为 `C序号_用途`。

## 5. 复杂项目数据组织（FB 背景与全局 DB / UDT）
- 多工位同构设备（如多台电机、多组气缸）可使用 `FB` 封装标准控制逻辑，内部状态与定时器（`TON_TIME`）存放在 `FB` 的 `Static` 静态变量区（配合独立背景 DB 或上级 `FB` 多重背景），避免 `%M` 区过度膨胀。
- 工艺配方、步序状态字、通信收发缓冲区、模拟量滤波数据可存放在优化访问的全局 `DB`（配合 `UDT` 结构体定义接口）。
- 外部实物信号（`%I` / `%Q`）优先通过 `FB` 的 `Input` / `Output` 形参传入传出，便于同一 `FB` 多处复用及新手在调用段直接查看实参连线。
