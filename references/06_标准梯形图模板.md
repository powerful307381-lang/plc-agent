# 06 标准梯形图模板

> 下面用“文字版梯形图”描述逻辑：`→` 表示串联，`∥` 表示并联，`[NC接线]` 表示现场接常闭、程序中用常开触点扫描，`-|/|-` 表示程序中的常闭触点。生成 XML 时，严格按程序段拆分。

## 1. 程序段注释（调试指导）固定格式
每个程序段的 **Title** 和 **Comment** 必须按下面格式填写：
```
标题：NW3 1号电机 —— 正转启动与自锁
注释：
【功能】按下正转启动按钮，KM1 吸合，电机正转；松开按钮后靠 KM1 自锁保持运行。
【动作条件】安全条件满足(M10.1=1) 且 停止按钮未按下(I0.2=1) 且 热继正常(I0.3=1) 且 反转未运行(KM2=0) 且 处于手动模式。
【互锁说明】串入 KM2 常闭做软件互锁，防止正反转同时吸合造成相间短路；图纸中 [有/无] 硬件互锁。
【现场不动作排查】
 1. 看 PLC 上 I0.0 指示灯：按下按钮时灯不亮 → 查按钮/接线（线号104）。
 2. 在博途中“启用监视”，看本程序段哪个触点没有导通（不导通的显示为虚线/灰色）。
 3. Q0.0 灯亮但 KM1 不吸合 → 查 KM1 线圈电源、硬件急停回路、热继 95-96。
 4. 急停或热继复位后，需要重新按启动按钮。
```

## 2. FC1_安全与模式（每个项目必有）
| NW | 逻辑 |
|---|---|
| NW1 急停 | `SB0_急停按钮[NC接线]` → `M_急停正常` |
| NW2 安全汇总 | `M_急停正常` → `QF/安全门等[NC接线]` → `M_安全条件满足` |
| NW3 故障复位 | `SB_复位按钮` → P_TRIG(`M_边沿_复位按钮`) → `M_故障复位` |
| NW4 手动模式 | `SA1_手自动选择(手动挡)` → `M_手动模式`（若为单 DI 两档旋钮：1=自动/0=手动，则手动模式直接取 `-|/|- SA1_手自动选择`） |
| NW5 自动模式 | `SA1_手自动选择(自动挡)` → `-\|/\|- M_手动模式` → `M_自动模式`（若为单 DI 两档旋钮，则直接 `SA1_手自动选择` → `M_自动模式`） |
规则：模式切换时，自动流程的所有状态位必须复位（程序段：`M_手动模式` 上升沿 → R 复位自动步序位）；急停在两种模式下都有效。

## 3. 模板 A：电机正反转
| NW | 逻辑 |
|---|---|
| 正转 | (`SB_正转启动` ∥ `KM1`自锁) → `SB_停止[NC接线]` → `FR[NC接线]` → `M_安全条件满足` → `-\|/\|- KM2`(软件互锁) → `-\|/\|- SB_反转启动`(按钮互锁，可选) → `SQ_正转限位[NC接线]`(如有) → `KM1_正转` |
| 反转 | 与正转对称 |
| 热继报警 | `-\|/\|- FR` → S `M_报警_热继`；`M_故障复位` → `FR`(常开) → R `M_报警_热继` |
自动模式下，用 `M_xx正转请求` 代替按钮作为启动条件（与手动按钮并联，并分别串入对应的模式位）。

## 4. 模板 B：星三角降压启动（KM1 主 / KM2 星 / KM3 角）
| NW | 逻辑 |
|---|---|
| 主接触器 | (`SB_启动` ∥ `KM1`自锁) → `SB_停止[NC]` → `FR[NC]` → `M_安全条件满足` → `KM1` |
| 星形计时 | `KM1` → `-\|/\|- KM3` → TON `T1_星三角切换`(PT 默认 T#6S，**注释提示根据电机功率调整 4~10S**) |
| 星形 | `KM1` → `-\|/\|- T1.Q` → `-\|/\|- KM3`(互锁) → `KM2_星形` |
| 换接延时 | `KM1` → `T1.Q` → `-\|/\|- KM2` → TON `T2_星三角换接延时`(T#300MS，防止星/角同时吸合造成电弧短路) |
| 角形 | `KM1` → (`T2.Q` ∥ `KM3`自锁) → `-\|/\|- KM2`(互锁) → `KM3_角形`（**`KM3` 自锁分支仅并联绕过 `T2.Q`，必须在 `KM1` 常开触点之后，确保停机或安全断开时 `KM3` 立即失电**） |
注释中必须说明：**星形和三角形接触器绝不能同时吸合**，必须同时有硬件和软件互锁。

## 5. 模板 C：气缸 + 磁性开关
先确认电磁阀类型（识图时提问）：**单电控（弹簧复位）** 或 **双电控**。
| NW | 逻辑 |
|---|---|
| 伸出指令 | 手动：`SB_伸出` → `M_手动模式`；自动：`M_伸出请求` → `M_自动模式`；两者并联 → `M_安全条件满足` → `-\|/\| B_缩回到位`以外的条件按工艺决定 → `YV_伸出` |
| 单电控 | `YV_伸出` 用 S/R 置位复位（或自锁保持）：伸出指令 → `S` 置位保持得电；**收到缩回指令（手动缩回按钮 / 自动工艺退回步）或急停/安全条件不满足** → `R` 复位失电（弹簧复位缩回；严禁伸出到位即复位，否则无法维持伸出动作） |
| 双电控 | `YV_伸出` 与 `YV_缩回` 互锁，**两个线圈不得同时得电**；伸出到位后可断开 `YV_伸出` 保持位置，缩回时再触发 `YV_缩回` |
| 超时报警 | `YV_伸出` → `-\|/\| B_伸出到位` → TON `T_伸出超时`(T#5S) → S `M_报警_气缸伸出超时` |
排查注释必须包含：气源压力、磁性开关指示灯、节流阀、电磁阀手动按钮的测试方法。

## 6. 模板 D：变频器（硬接线数字量）
| 信号 | 说明 |
|---|---|
| DO 正转 / 反转 | 两者互锁（与模板 A 相同的逻辑结构，只是驱动对象是变频器 DI，而不是接触器） |
| DO 多段速 | 用 MOVE 或线圈组合按工艺选择，注释中写明“速度参数在变频器面板中设置，参数号见变频器手册” |
| DI 故障 | 识图时确认触点类型；故障 → 停止正/反转输出并 S `M_报警_变频器故障`；复位需要按复位按钮 |
| DI 运行反馈 | 输出指令发出后 T#3S 内没有收到反馈 → 报警 |
注释中必须提醒：“PLC 程序只给出启停信号，加速/减速时间、频率等参数需要在变频器面板中设置。”

## 7. 模拟量备用模板（仅在识图发现且用户确认后启用）
- 输入：`NORM_X`(MIN=0, VALUE=%IW64, MAX=27648) → `SCALE_X`(MIN=0.0, MAX=50.0) → `MD200 M_变频频率反馈_Hz`
- 输出：`NORM_X`(0.0~50.0) → `SCALE_X`(0~27648) → `%QW64`
- 注释中说明 27648 是 S7-1200 模拟量的满量程数值；4-20mA 信号需要在硬件组态中设置测量类型。

## 8. 模板 E：产线自动步序与机械防撞联锁（多工位协调必用）
1. **自动步序状态位（`build_step_latch_network`）**：
   - 结构：`(前一步状态位 → 转移条件 ∥ 本步状态位自锁) → M_自动模式 → M_安全条件满足 → -|/|- M_报警汇总 → -|/|- 下一步状态位 → 本步状态位 (Coil)`。
   - 优势：每个步序 `M` 位仅有一个普通线圈 `Coil`（零双线圈风险），急停、切手动或发生超时报警时自动安全清零。
2. **手/自动执行器防撞控制（`build_manual_auto_interlocked_actuator_network`）**：
   - 结构：`([手动点动 -> M_手动模式] ∥ [自动请求 -> M_自动模式] [∥ 回原位请求]) → M_安全条件满足 → 机械防撞到位传感器 / 热继 / 互斥常闭(-|/|-) → 执行器 %Q 线圈`。
   - 铁律：所有机械防干涉联锁触点**必须串联在 `O` 节点汇流后的公共主干路上**，保证手动调试点动和自动生产均受保护，同时严格满足 S3/S4/S5 拓扑审计。

## 9. FC90 报警汇总 / FC91 指示灯
- `FC90`：所有 `M_报警_*` 并联 → `M_报警汇总`。
- `FC91`：运行灯 = 任一设备运行；故障灯 = `M_报警汇总` 串 时钟位闪烁（**只有在阶段 0 确认时钟存储器已启用时**才使用 `"Clock_1Hz"`，否则用 TON 自建闪烁）；急停灯 = `-|/|- M_急停正常`。

## 10. OB1
按顺序调用：`FC1` → 各设备 FC → `FC90` → `FC91`。每次调用占一个程序段，标题写明被调用 FC 的作用。
