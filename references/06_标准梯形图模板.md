# 06 标准梯形图模板（微功能闭环合段版）

> 下面用“文字版梯形图”描述逻辑：`→` 表示串联，`∥` 表示并联，`[NC接线]` 表示现场接常闭、程序中用常开触点扫描，`-|/|-` 表示程序中的常闭触点，`[多梯级]` 表示同一个程序段（Network）内从左母线上下并列的强关联梯级（1~4 条，一屏可读）。生成 XML 时，优先使用 `lad_builder.py` 的复合程序段构建器按微功能闭环合并，**严禁拆成单线圈碎段或硬造同块一次性过渡 `%M` 位**。

## 1. 程序段注释（调试指导）固定格式
每个程序段的 **Title** 和 **Comment** 必须按下面格式填写（复合段需按支路逐条说明，避免大段堆砌）：
```
标题：NW1 1号电机 —— 正反转手自动与互锁控制
注释：
【功能】控制 1 号电机正转 KM1 与反转 KM2，手自动分流且共用安全/热继/互斥保护。
【支路1 正转 KM1】手动正转点动∥自动正转请求 → M_安全条件满足 → FR1热继 → -|/|- KM2(互锁) → KM1。
【支路2 反转 KM2】手动反转点动∥自动反转请求 → M_安全条件满足 → FR1热继 → -|/|- KM1(互锁) → KM2。
【现场不动作排查】
 1. 看 PLC 输入灯：对应按钮/传感器触发时输入灯不亮 → 查按钮、限位或接线端子。
 2. 启用博途“监视”：查看本段对应梯级哪个串联触点显示虚线（未导通），优先核查 M_安全条件满足、FR1 及对方互锁触点。
 3. Q 灯亮但接触器不吸合 → 查线圈电源、硬件互锁常闭触点及热继 95-96。
```

## 2. 按项目规模自适应分块规则（消灭迷你空壳 FC）
- **小型单机项目（≤15 I/O 或单一机构/输送带）**：固定收敛为 **2 个业务 FC + 可选 `FC99`**，彻底消除 1~2 段的空壳小块：
  - **`FC1_安全模式与报警`（3~4 个复合段）**：安全准入+急停/热继报警 S/R、手自动模式+系统启停、超时监控+报警汇总。
  - **`FC2_<设备工艺与输出>`（3~6 个复合段）**：自动步序+本步延时、执行器手自动防撞输出、状态指示灯组。
- **中大型多工位产线**：`FC1_全局安全与模式` + 按工位/功能划分的业务 `FC/FB` + `FC90_全局报警与指示灯`（**将原 `FC90_报警汇总` 与 `FC91_指示灯` 合并为同一公用块**，杜绝仅 1 段的孤立 FC）。

## 3. 安全、模式与报警闭环模板（合段范式）
| NW | 合并内容（多梯级） | 对应构建函数 |
|---|---|---|
| NW1 安全准入与安全报警 | 梯级1：`SB0_急停[NC接线]` → `QF/安全门[NC接线]` → `M_安全条件满足`<br>梯级2：`-\|/\|- SB0_急停` → S `M_急停报警`；梯级3：`SB0_急停` → `SB_复位` → R `M_急停报警` | `build_composite_network` |
| NW2 手自动模式切换 | 梯级1：`SA1_手自动` → `M_安全条件满足` → `M_自动模式`<br>梯级2：`-\|/\|- SA1_手自动` → `M_安全条件满足` → `M_手动模式`（可扩展系统启动自锁与手动点动梯级） | `build_mode_select_network` |
| NW3 超时监控与报警汇总 | 梯级1：`使能条件` → `TON(T1, PT)` → S `M_报警_超时`<br>梯级2：`M_故障复位` → R `M_报警_超时`<br>梯级3：`M_急停报警 ∥ M_热继报警 ∥ M_报警_超时` → `M_报警汇总` | `build_timeout_alarm_network` |
规则：模式切换时，自动步序通过串联 `M_自动模式` 自动清零；急停在两种模式下都有效。

## 4. 模板 A：电机正反转（同设备合段，跨设备分段）
| NW | 合并内容（多梯级） | 说明 |
|---|---|---|
| NW_电机启停 | 梯级1：(`SB_正转` ∥ `KM1`或`自动正转`) → `M_安全条件满足` → `FR[NC]` → `-\|/\|- KM2` → `KM1_正转`<br>梯级2：(`SB_反转` ∥ `KM2`或`自动反转`) → `M_安全条件满足` → `FR[NC]` → `-\|/\|- KM1` → `KM2_反转` | 使用 `build_dual_interlocked_actuators_network`，禁止跨电机混放 |
| NW_热继报警 | 梯级1：`-\|/\|- FR` → S `M_报警_热继`<br>梯级2：`M_故障复位` → `FR` → R `M_报警_热继` | 使用 `build_sr_latch_network` |

## 5. 模板 B：星三角降压启动（由 5 段压至 2 段，0 过渡 M 位）
| NW | 合并内容（多梯级） | 说明 |
|---|---|---|
| NW1 主控与双计时 | 梯级1：(`SB_启动` ∥ `KM1`自锁) → `SB_停止[NC]` → `FR[NC]` → `M_安全条件满足` → `KM1`<br>梯级2：`KM1` → `-\|/\|- KM3` → `TON(T1_星三角切换, T#6S)`<br>梯级3：`KM1` → `全局定时器.T1_星三角切换.Q` → `-\|/\|- KM2` → `TON(T2_换接延时, T#300MS)` | 调用 `build_star_delta_networks`，直接引用定时器 `.Q` 触点，不设多余过渡 M 位 |
| NW2 星角互锁输出 | 梯级1：`KM1` → `-\|/\|- T1.Q` → `-\|/\|- KM3` → `KM2_星形`<br>梯级2：`KM1` → (`T2.Q` ∥ `KM3`自锁) → `-\|/\|- KM2` → `KM3_角形` | `KM3` 自锁位于 `KM1` 之后，停机或安全断开瞬间失电；必须配置硬件+软件双互锁 |

## 6. 模板 C：气缸 + 磁性开关（同气缸合段）
先确认电磁阀类型：**单电控（弹簧复位）** 或 **双电控**。
| NW | 合并内容（多梯级） | 说明 |
|---|---|---|
| 驱动输出 | **单电控**：(`SB_伸出`→`M_手动模式` ∥ `M_伸出请求`→`M_自动模式`) → `M_安全条件满足` → 防撞条件 → `YV_伸出`（严禁将伸出到位传感器常闭串入单电控自断！）<br>**双电控**：梯级1 `YV_伸出`（串 `-\|/\|- YV_缩回`）与 梯级2 `YV_缩回`（串 `-\|/\|- YV_伸出`）合为同 1 段 | 双电控使用 `build_dual_interlocked_actuators_network` |
| 超时报警 | 梯级1：`YV_伸出` → `-\|/\|- B_伸出到位` → `TON(T_伸出超时, T#5S)` → S `M_报警_气缸伸出超时`<br>梯级2：`M_故障复位` → R `M_报警_气缸伸出超时` | 使用 `build_timeout_alarm_network`，0 过渡位 |
排查注释必须包含：气源压力、磁性开关指示灯、节流阀、电磁阀手动按钮的测试方法。

## 7. 模板 D：变频器（硬接线数字量）与模拟量
- **数字量正反转 + 多段速**：同台变频器正反转启停合并为 1 段；故障报警置位与复位合并为 1 段，注释写明“加减速时间与频率参数在变频器面板中设置”。
- **模拟量（仅识图确认后启用）**：`NORM_X`(0..27648) → `SCALE_X`(0.0..50.0) → `MD200`（同段串接），输出反向缩放至 `%QW64`；注释说明 27648 为 S7-1200 满量程及 4-20mA 硬件测量类型设置。

## 8. 模板 E：产线自动步序与机械防撞联锁（合段范式）
1. **自动步序状态位（无定时用 `build_step_latch_network`；带本步延时用 `build_step_with_timer_network`）**：
   - 带延时的步序必须把本步自锁（梯级1，直接串入 `-\|/\|- 全局定时器.Tx.Q` 退出）与本步 `TON` 计时（梯级2）合在同 1 个程序段内，严禁另建 `M_Tx完成` 过渡位。
2. **手/自动执行器防撞控制（`build_manual_auto_interlocked_actuator_network` / `build_dual_interlocked_actuators_network`）**：
   - 所有机械防干涉联锁触点**必须串联在 `O` 节点汇流后的公共主干路上**，保证手动点动与自动生产均受保护。

## 9. 报警汇总与指示灯组（`FC90_全局报警与指示灯` / `build_indicator_lamps_network`）
- 多工位产线中，将原仅 1 段的 `FC90_报警汇总` 与 `FC91_指示灯` 合并为 **`FC90_全局报警与指示灯`**：NW1 报警汇总（或由超时段兼并），NW2 运行灯 + 故障灯 + 急停灯多梯级同段输出（仅阶段 0 确认时钟存储器已启用时方可使用 `"Clock_1Hz"`）。

## 10. OB1
按收敛后的顺序调用各功能块（如单机项目仅调用 `FC1` → `FC2` [→ `FC99`]；产线项目调用 `FC1` → 工位块/FB → `FC90` [→ `FC99`]）。每次调用占一个程序段，标题写明被调用块的作用。
