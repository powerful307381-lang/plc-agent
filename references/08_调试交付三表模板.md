# 08 《现场调试交付三表》模板

输出文件：`05_现场调试交付三表.xlsx`（用 openpyxl 生成，中文字体用“微软雅黑”，冻结首行，开启自动筛选，A4 横向打印，每页重复打印表头），同时生成 `.md` 预览。

## 首页 Sheet「说明」
项目名、日期、图纸版本、PLC 型号、程序版本；🔴 安全问题清单（来自识图阶段，例如缺少硬件互锁）；安全声明（见 `03` 第 5 节）；尚未关闭的 `⚠待确认` 清单。

## 表一 Sheet「I/O打点表」
用途：上电后不运行程序，逐点核对接线（打点 = 逐个信号测试）。
| 序号 | PLC地址 | 变量名 | 元器件代号 | 图纸位置 | 端子/线号 | NO/NC | 信号说明 | 测试方法 | 预期现象 | 实测结果(√/×) | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | %I0.0 | SB0_急停按钮 | -SB0 | 3.2 | 11-12/101 | NC | 急停 | 松开急停 → 按下急停 | 松开时 I0.0 灯**亮**，按下时**灭** | | |
| 2 | %Q0.0 | KM1_1号电机正转 | -KM1 | 6.2 | A1/201 | 线圈 | 正转接触器 | **断开主回路**后，在监控表中强制 Q0.0 | KM1 吸合，有“咔哒”声 | | |
规则：
- 输入点：写明“动作前/动作后”PLC 指示灯的预期状态；NC 信号要特别强调“平时灯亮”。
- 输出点：必须注明“断开主回路电源（只保留控制电源）后再测试”；变频器 DO 注明“确认电机未接负载”。
- 备用点列出，并标注“备用”。

## 表二 Sheet「单机空载调试步骤」
按设备分组，每台设备都按下列顺序编写：
| 步骤 | 设备 | 操作 | 前置条件 | 预期现象 | 对应程序段 | 结果 | 异常时查看 |
|---|---|---|---|---|---|---|---|
| 1 | 通用 | 断开所有主回路断路器，只合控制电源 | — | PLC RUN 灯亮，无 ERROR | — | | |
| 2 | 通用 | 急停复位、按复位按钮 | — | M_急停正常=1 | FC1/NW1 | | 速查表 E01 |
| … | 1号电机 | 手动模式点动正转（**电机脱开机械负载**） | 安全条件满足 | KM1 吸合，电机转向正确；方向反了就调换任意两相 | FC2/NW1 | | 速查表 E1x |
固定包含的测试项：急停测试（运行中按下急停必须立即停机，复位后不得自动启动）、热继测试（按热继的 TEST 按钮）、互锁测试（正转运行中按反转无效）、限位测试、手动/自动切换测试、星三角切换时间观察、气缸到位与超时测试、变频器故障模拟。

| 编号 | 故障现象 | 可能原因（按概率从高到低排列） | 检查点（PLC地址/端子/线号） | 博途监控看哪里 | 处理方法 |
|---|---|---|---|---|---|
| E01 | 所有设备都无法启动 | 急停被按下/急停线断/安全条件不满足 | %I0.0，线号101 | FC1/NW1、NW2 | 复位急停，量 11-12 通断 |
| E11 | 1号电机按启动不转，Q0.0 不亮 | 停止按钮 NC 断开/热继跳闸/反转在运行/模式不对 | %I0.2、%I0.3 | FC2/NW1 哪个触点不通 | … |
| E12 | Q0.0 亮但 KM1 不吸合 | 硬接线急停回路断开/KM2 硬件互锁触点/线圈烧坏/控制电源 | 线号201、KM2 21-22 | — | 量线圈 A1-A2 电压 |
规则：每台设备至少写出“不启动 / 启动后马上停 / 无法停止 / 互锁失效 / 报警不能复位”5 类故障；每一条都对应到具体程序段。

## 4. 反向一键生成交付三表（`reverse_to_delivery_tables.py`）
针对现场已有博途定稿项目，支持直接调用脚本逆向解析并输出交付三表：
```bash
# 方式 1：指定本地已导出的 XML 项目目录
python <技能目录>/scripts/reverse_to_delivery_tables.py "项目/OP10_星三角压装工位_20261028"

# 方式 2：附加到当前已打开的博途进程，自动导出并生成
python <技能目录>/scripts/reverse_to_delivery_tables.py --from-tia --out-dir "项目/某项目/05_交付"
```
脚本将自动解析所有 TagTable 与梯形图逻辑，生成排版精致的《05_现场调试交付三表.xlsx》、《05_现场调试交付三表.md》及《PLC变量表_中文.xlsx》。
