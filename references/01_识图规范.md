# 01 识图规范（EPLAN 电气图 → 识图清单）

## 1. 读取顺序
1. **封面 / 目录页**：项目名、图纸页数、页码规则（如 `=A1+B1/3` 表示功能=A1、位置=B1、第 3 页）。
2. **主回路页**：电机、接触器主触点、热继电器、断路器、变频器动力端，用来判断设备类型（正反转 / 星三角 / 变频）。
3. **控制回路页**：急停、按钮、接触器线圈、硬件互锁、安全继电器。
4. **PLC 卡片页（重点）**：每个通道的地址、端子号、外部元器件、线号。
5. **端子图 / 电缆图**（如果有）：用来补全端子号和线号。

PDF 带文字层时，**优先提取文字**（如用 `pdfplumber`/`PyMuPDF` 提取文字和坐标），再结合页面图像核对；纯图片输入时用视觉识别，并给每一项标注置信度。
若用户已从 EPLAN 导出结构化《PLC 地址与通道分配表》（`.xlsx`/`.csv`）、《设备 BOM 表》及《产线工艺动作步序表》《机械防呆与安全联锁矩阵表》，**优先调用 `scripts/eplan_parser.py` 自动解析并生成四方对账报告**，详见 [09_产线级EPLAN导出与工艺输入规范.md](09_产线级EPLAN导出与工艺输入规范.md)。

## 2. 页码.列号（交叉引用）
- EPLAN 图框顶部有列号 `0 1 2 … 9`，左侧有行号 `A B C …`。
- 本技能统一使用 `页码.列号`，例如 `3.5` = 第 3 页第 5 列。
- 交叉引用写法如 `/3.5`、`=A1+B1/3.5`，记录时去掉结构前缀，只保留 `3.5`。
- 同一元器件的线圈与触点分在不同页时，**以接入 PLC 的那个触点所在位置为准**写入注释。

## 3. 元器件代号识别（IEC 81346 常见字母）
| 代号 | 含义 | 常见触点/端子 |
|---|---|---|
| `-SB` | 按钮（`-SB0` 常用于急停） | 急停 NC：`11-12`；启动 NO：`13-14`；停止 NC：`11-12` |
| `-SA` | 选择开关（手动/自动） | 按挡位区分 NO |
| `-KM` | 接触器 | 主触点 `1-2/3-4/5-6`，辅助 NO `13-14`，辅助 NC `21-22` |
| `-KA` | 中间继电器 | NO `x3-x4`，NC `x1-x2` |
| `-FR`/`-F` | 热继电器 | **NC `95-96`（必须用这一组）**，NO `97-98` |
| `-QF` | 断路器 | 辅助触点 |
| `-SQ`/`-BG` | 限位开关 / 位置开关 | 限位保护用 NC |
| `-B`/`-BG` | 传感器（磁性开关、光电开关） | 注意 PNP/NPN、棕+/蓝-/黑信号 |
| `-YV`/`-MB` | 电磁阀 | 线圈 A1/A2 |
| `-HL`/`-PF` | 指示灯 | X1/X2 |
| `-T`/`-TA`/`-U` | 变频器 | DI1、DI2…，RA/RB/RC 故障继电器，AI1 |
| `-A`/`-K` | PLC / 安全继电器 | |

**NO/NC 判断口诀**（IEC 60947 端子编号的**个位数**）：`1-2` = 常闭 NC，`3-4` = 常开 NO，`5-6` = 延时常闭，`7-8` = 延时常开。
图形符号和端子号矛盾时，标 `⚠待确认`。

## 4. PLC 卡片页解析
对每个通道记录：
| 字段 | 示例 |
|---|---|
| PLC 地址 | `%I0.0` |
| 卡片端子 | `DIa.0` / `X10:2` |
| 外部元器件 | `-SB0` |
| 元器件端子 | `11-12` |
| 线号 | `101` |
| 位置 | `5.3` |
| 信号类型 | DI / DO / AI / AQ |
| NO/NC | NC |

- 图纸上**没有写地址**、只写了通道号或采用通用/日系端子编号（如 `X0` / `COMX`、`Y1` / `Y2` / `COMY`）时，按 S7-1200 本体默认地址给出候选映射（如 `X0 → %I0.0?`、`Y1 → %Q0.0?`、`Y2 → %Q0.1?`），**同时标记 `⚠待确认`，并在阶段 0 读到的博途实际组态中核对**。地址以博途组态为准，冲突或存在跳号时在【关卡①】向用户提问。
- 备用通道（空着的）也要列出，标注“备用”。

## 5. 安全专项检查（必须逐项输出结论）
| 检查项 | 判定方法 | 不合格时 |
|---|---|---|
| 急停接法 | PLC 输入是 NC（11-12），并且控制回路中急停串在接触器线圈公共端 | 🔴 标红，写明风险 |
| 热继 | 使用 95-96 NC 接入 PLC 或串在线圈回路 | 🔴 |
| 限位 | 极限保护限位为 NC | 🔴 |
| 正反转硬件互锁 | KM1 线圈回路串有 KM2 的 21-22，KM2 线圈回路串有 KM1 的 21-22 | 🔴 “缺硬件互锁，仅靠程序互锁有短路风险” |
| 星三角硬件互锁 | 星形接触器与三角形接触器之间相互串入 NC | 🔴 |
| 变频器故障信号 | 用的是故障继电器的哪一组（常开还是常闭），故障时 PLC 收到 0 还是 1 | ⚠待确认 |

## 6. EPLAN 图纸 vs 博途硬件组态“自动对账差异表”
在阶段 1 完成初步 I/O 提取后，必须调用 `scripts/tia_connect.py` 的 `compare_eplan_with_tia_hw()` 自动与阶段 0 读取的博途硬件配置比对：
1. **核对每一路实物地址（`%I` / `%Q`）是否均落在博途已组态硬件模块内**：
   - 本体 CPU（例如 S7-1200 1214C 本体 DI 为 `%I0.0`～`%I1.5`，DQ 为 `%Q0.0`～`%Q1.1`）；
   - 信号板 SB（例如槽位 101 的 SB1223 2DI/2DQ，地址通常为 `%I4.0`～`%I4.1` / `%Q4.0`～`%Q4.1`）；
   - 扩展模块 SM（例如槽位 2 的 SM1221 8DI，地址通常为 `%I8.0`～`%I8.7`）。
2. **越界、缺失与电气规格不匹配告警**：
   - 若图纸出现 `%I8.0` 但博途硬件树中未插入对应的 SM 扩展模块，或者模块起始地址被误设为 `%I2.0`，立即在识图清单中醒目标注“🔴 硬件组态越界/缺失”，并给出中文整改指引（“请在博途设备组态中插入 SM 1221 并将输入起始地址修改为 8”）。
   - **CPU 供电与输出电气类型核对**：核对阶段 0 读取的 CPU 订货号（如 `6ES7 214-1AG40-0XB0` 为 `1214C DC/DC/DC`，24V DC 供电 + 24V DC 晶体管输出；`1BG40` 为 `AC/DC/Rly`，220V AC 供电 + 继电器输出）。若图纸 PLC 标注 `L / N`（220V AC）供电或接触器线圈为 220V AC 且未通过中间继电器隔离，必须醒目标注 🔴 电气规格不匹配，并在【关卡①】向用户确认现场真实硬件方案。
   - **极简图纸缺少急停/热继接点的处理**：若图纸中完全没有急停按钮（`-SB0`）或热继辅助触点（`95-96`）接入 PLC，必须在安全专项检查中标红 🔴，并在【关卡①】给出选项：A. 预留/补接急停与热继 DI 通道；B. 仅作软件教学/演示，暂由 `FC1` 生成软件安全条件并在交付物醒目标注安全风险。
